# 🎯 TirAuxKirby

Un mini-jeu fun et rapide en 3D réalisé avec [Three.js](https://threejs.org/), où votre seul objectif est de tirer sur **tous les Kirby** ! 🌀

## 🎮 Gameplay

- Déplacez votre viseur avec la souris
- Cliquez pour tirer
- Éliminez tous les Kirby le plus vite possible
- Sons cartoon et ambiance fun

Le jeu se joue directement dans le navigateur, aucune installation n’est nécessaire.

👉 [Tester le jeu en ligne](https://tirauxkirby.vercel.app)

---

## 🧰 Technologies utilisées

- [Three.js](https://threejs.org/) pour le rendu 3D
- HTML / CSS / JavaScript
- Sons intégrés pour plus d'immersion
